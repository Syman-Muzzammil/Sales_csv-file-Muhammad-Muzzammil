Sunday Project_Data Quality , Insights and CSV Operations

Project Overview

This project focuses on data cleaning, data quality analysis, business insights, data visualization and CSV file manipulation using Python.

The project uses a raw sales dataset (sales_raw.csv) to identify data quality issues, clean the dataset, calculate revenue, analyze sales performance, create visualizations and perform CSV operations.

The project is divided into two parts: Part A (Data Quality and Basic Insights) and Part B (CSV File Handling and Manipulation).
